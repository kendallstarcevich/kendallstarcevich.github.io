> Flask-RESTful API that serves as a python wrapper

This project is a simple Flask-RESTful API that serves as a wrapper for the public [NBA Statistics Go](https://documenter.getpostman.com/view/25652688/2sB34Zs4xZ) API. It provides endpoints to fetch total player statistics for a given season and team, and demonstrates handling for both GET and POST requests, input validation, and custom error messages.

It was an assignment for my **Software Engineering** Course.
