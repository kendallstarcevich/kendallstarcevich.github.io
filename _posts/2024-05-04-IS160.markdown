# Database Project: MVC Men’s & Women’s Basketball

Below is the report for my Final Project for my database management course. We used **SQL** to analyze to understand each MVC institution’s financial impacts on both the men’s and the women’s basketball teams pertaining to each individual team, gender disparities, and size and locational impacts. This document includes screenshots and code for all of the **data cleaning steps**, an **entity relationship diagram** of the 5 tables we created in Visio, and visualizations in **PowerBI.**
